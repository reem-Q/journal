# JournalApp

A small, native SwiftUI journal for iPhone inspired by the supplied reference design.

## Features

- Dark, purple-accented interface
- Empty state for first launch
- Create and edit journal entries in a sheet
- Delete entries from each card's menu
- Entries persist locally with `UserDefaults`
- Dynamic Type and VoiceOver-friendly controls

## Run

1. Open `JournalApp.xcodeproj` in Xcode 16 or later.
2. Choose an iPhone simulator.
3. Press Run.

The project targets iOS 17 and has no third-party dependencies.
